## Games

### [Abyss Survivors](https://github.com/WAGNER47/Abyss-Survivors-Bot)

[Play on Telegram](https://t.me/AbyssSurvivorsbot) · [Play on the web](https://abyss-survivors-v21-telegram-sdk.vercel.app)

A deep-sea survivor roguelite with 27K daily players. You dive through 100 levels, stack weapons and elements, and fight Wardens on the way down. It ships in six languages, Farsi included. I built the game, its build and test scripts, and the Vercel backend that runs friends and stats.

`JavaScript` `Telegram Mini App` `Vercel` `Upstash Redis`

### [Blind Gambit](https://github.com/WAGNER47/Blind-Gambit)

[Play in your browser](https://wagner47.github.io/Blind-Gambit/)

A chess roguelite where each move scores Chips × Mult. You spend your winnings on perks between rounds while the man across the table changes every round and learns how you play.

`JavaScript` `HTML/CSS` `One file, no libraries`

## Tools

### [Vira Engine](https://github.com/WAGNER47/Vira-Engine)

[Open the editor](https://wagner47.github.io/Vira-Engine/) (desktop)

A no-code 3D game editor that runs offline from one HTML file. You build levels, rooms, terrain, animation, sound and cutscenes in one window, then press Play. Logic Tiles let you write game behavior as short sentences instead of node graphs. In active development.

`Three.js` `cannon.js` `JavaScript`
